# orbit

Orbit is a cross-platform productivity and project management app built to organize workspaces, projects, milestones, and tasks in a simple and structured way.  It supports multiple workspaces, team collaboration, task assignment, deadlines, and nested subtasks for better workflow management.  Built with an offline-first architecture using Drift, Supabase, and PowerSync, Orbit ensures fast performance, reliable offline access, and seamless synchronization across devices.  Available on mobile and desktop with both light and dark themes.
